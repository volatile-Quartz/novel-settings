# 设定库新增与确认补充包（最终整合版）

## 一、核心角色新增/修正设定

### 1. 天宫艾丽卡（超能力与战斗设定）
- **能力类型**：接触系超能力（金属操纵）。
- **发动条件**：必须身体直接接触金属才能发动（类似插头插入插线板通电），松手即断开连接。
- **限制机制（算力/内存上限）**：无法凭空操纵庞大金属构造（如大楼、汽车），有严格的体积与算力上限。只能控制接触部分的一小片金属，进行极高精度的变形或硬化。
- **战斗风格**：依赖极强体质与神经反射进行近战微操。可通过接触赋予金属动能后投掷，或直接使用科学侧远程武器。
- **副本限制**：在零次元AI系统内（纯数据世界），无实体金属，该超能力无法发动，仅能依靠系统武器（正弦枪）和自身体质。

### 2. 未来女儿（外貌修正）
- **外貌**：由原设定的“白发、樱粉尾”修正为**“蓝发、白尾”**。
- **视觉逻辑**：蓝发继承自澪音的深色系（提炼为蓝），白尾继承自由奈的浅色系。与由奈的“白发粉尾”形成镜像反差。称呼澪音为“妈妈”，称呼艾丽卡为“阿姨”。

### 3. Ingrid（反套路支线与背景）
- **定位反差**：拥有传统异世界穿越小说主角的配置（系统面板、穿越者），但实际是重要配角（支线主角），澪音才是全书主角。
- **出身背景**：在魔法侧是普通家庭出身，凭借优异成绩作为特招生进入光之学院。入学典礼上台讲话引起贵族少爷注意，后在无人的地方遭遇霸凌。
- **与Lucilla的结缘**：遭遇霸凌时被隐藏身份的Lucilla用光魔法救下。因被Ingrid的“系统面板”识破伪装，Ingrid得知其公主身份，随后作为“跟班”待在Lucilla身边，替不方便露面的公主处理事务。
- **面板限制**：系统面板无法读取由奈的数据（显示为“？？？”）。
- **外场高光**：二卷结尾，澪音与由奈进入白色空间时，外部由Ingrid（面板战术支持）与Lucilla（光之女神转世，光系魔法防御）共同抵御反派三人组。
- **日常细节**：因是现实世界穿越者，日常会漏出“高三”、“程序BUG”等现代词汇，随后尴尬掩饰。

### 4. 由奈（种族与室友设定）
- **种族**：半人半吸血姬的混血。兼具人类一半的含蓄、内耗（导致怕生），以及血族一半的直球与占有欲本能。
- **由奈室友（影之学院）**：非人类种族（具体待定），性格开朗直爽。知道由奈幼年误认澪音为男孩的秘密，作为情感军师，以非人类的直接思维怂恿由奈“不要像人类一样拉扯，直接A上去”，直接促成了海底初吻。

### 5. 紫毛（角色定位补充）
- **定位参考**：盖勾亚·腔棘（活化石、幸存者、复仇者）。
- **身世背景**：间接受害者。烨华是从其上级（或她爹）手中接过的权力。紫毛因实验事故失去全部亲友，成为无魔法、无超能力的通缉犯，一心向高层复仇。
- **反差内核**：极度干涸、渴望温暖/生命力。表面像活化石般冷硬，实则对自然、温润的事物有极强的憧憬。

## 二、世界观与道具设定补充

### 1. 七灵球体系（七曜）
- **总数**：全书共七个灵球。对应最朴素的自然元素：**日（光）、月（影）、金、木、水、火、土**。
- **已知状态**：光之灵球（日）已在第一卷随小女孩前往天界。
- **设定反差**：最原始的七曜元素设定，与全书高维AI系统、三角函数、微积分等科技魔法体系形成极致对比。

### 2. 第四卷“掉马”与信息差控制（设定前提）
- **三色小队敌对情绪演变**：敌对关系仅存在于第一卷能力未找回前。第一卷后期能力异变重构获取新能力后，态度已慢慢好转。第四卷两界合作时，已是战友关系。
- **魔法侧与Ingrid认知盲区**：魔法侧（光院/影院）及Ingrid，对科学侧发生的“三色夺能事件”完全不知情。不存在“斗篷人夺能”的概念。
- **艾丽卡对由奈的认知边界**：
  - 三卷初期，艾丽卡只当由奈是“澪音偷偷谈的女朋友/魔法侧普通学生”，完全不往斗篷人方向联想。
  - 三卷中期篝火夜谈公开信息后，艾丽卡也仅将由奈当做“澪音的童年玩伴+多年后重逢的恋人”，不产生任何身份联想。
- **紫毛的认知**：紫毛虽在第一卷与斗篷人交过手，但三卷面对软糯的由奈，完全没将两人联系在一起。
- **反派角色反应**：第四卷BOSS战由奈深吻澪音掉马时，因三色能力已升级且两界已合作，不会表现出愤怒。而是表现出极度的震惊、尴尬与手足无措（参考《放学后的昴星团》队友撞见亲密行为）。

### 3. 第三卷开局触发机制（确认版）
- **澪音与由奈**：二卷末白色空间事件后，在科学侧游乐园正式约会。被朔月以“避风头”为名派往外界，实则任务是寻找剩余灵球。
- **紫毛与艾丽卡**：紫毛躲避艾丽卡追捕在游乐园躲藏一天。约会快结束时，紫毛被逼死角触发游乐园空间裂缝。紫毛跃入，艾丽卡追捕。
- **被迫同行**：澪音与由奈正好在入口附近，与艾丽卡碰面，四人一同进入外界（第三个世界）。

### 4. 第三卷篝火夜谈（信息交互节点）
- **允许公开**：澪音和由奈公开童年误认男孩的相识经历；紫毛公开自己无超能力的体术使用者身份与事故背景（不涉及烨华）；艾丽卡公开追捕职责。
- **绝对隐瞒**：由奈隐瞒斗篷人及夺能身份；紫毛隐瞒针对烨华的具体复仇计划；澪音隐瞒体质细节。
- **节点作用**：确立四人小队的信任基础。艾丽卡和紫毛对由奈的认知停留在“软糯小女友”，确保了第四卷的核弹级反差。
